# App 设计规范（Flutter）

> 仅适用于手机 App。通用规范（颜色/字体/间距）见 [设计原则](design-system.md)。

---

## 🧭 导航结构

### 底部 Tab（3 个）

```
┌────────┬────────┬────────┐
│  🏠    │  ▶️    │  👤    │
│ 动态   │ 记录   │ 我的   │
└────────┴────────┴────────┘
```

| Tab | 路由 | 图标（未选中/选中）| 页面 |
|-----|------|-------------------|------|
| 动态 | `/feed` | `home_outlined` / `home` | FeedPage |
| 记录 | `/record` | `play_circle_outlined` / `play_circle` | ActivityRecordPage |
| 我的 | `/profile` | `person_outlined` / `person` | ProfilePage |

> 注：「发现」Tab 已隐藏（路段功能未上线），路由保留备用。

### 全屏页面（无底部 Tab）

| 路由 | 页面 | 入口 |
|------|------|------|
| `/login` | LoginPage | 未登录时 |
| `/register` | RegisterPage | 登录页"注册" |
| `/activity/:id` | ActivityDetailPage | Feed/Profile 点击活动 |
| `/profile/edit` | EditProfilePage | 我的 → 设置 → 编辑资料 |

## 📄 页面规范

### 登录页（`/login`）

```
┌─────────────────────────┐
│                         │
│       林立（32px 橙）    │  ← Display 字号
│  记录你的每一次运动       │  ← Body Small 灰
│                         │
│  [邮箱输入框          ]  │
│  [密码输入框          ]  │
│                         │
│  [    登录（Filled）  ]  │
│                         │
│     新用户？创建账号     │  ← TextButton
└─────────────────────────┘
```

- 无 AppBar，用 `SafeArea` + `Padding(24)`
- 标题居中，距顶部 80
- 登录失败：SnackBars 显示错误

### 录制页（`/record`）

**未开始**：4 个运动卡片（跑步/骑行/徒步/走路）
- 点击 → loading 遮罩（正在定位）→ 进入录制视图

**录制中**：
```
┌─────────────────────────┐
│  Mapbox 地图（60%）      │  ← 圆点 + 朝向 + 轨迹线
│                         │
├─────────────────────────┤
│  距离    时长    配速    │  ← 大数字统计
│                         │
│      [    暂停    ]      │
└─────────────────────────┘
```

### 活动详情（`/activity/:id`）

- 顶部：运动类型标题 + 返回箭头
- 地图（220 高，自适应轨迹边界）
- 4 列统计（距离/用时/配速/爬升）
- 详细数据列表（平均速度/最高速度/下降/热量/点数）

## 🎬 交互动画

| 场景 | 动画 |
|------|------|
| Tab 切换 | 系统默认（无自定义）|
| 进入录制 | loading 遮罩 → 淡出 |
| 地图定位 | puck 脉冲圈（橙色，500ms 呼吸）|
| 轨迹尾巴 | 停下 1 秒后渐隐（5 秒消失完）|
| 录制实时统计 | 数字直接更新（无动画，保证实时）|

| 返回键 | 系统返回 | 左上角箭头 |
